# Teach Reference and Migration

Teach remains the authoritative product and behavioral reference. It must not be discarded in a blind rewrite. A clean foundation reference may be generated by TOS to prove identity, authorization, tenant isolation, assignment, learner access, denial behavior, audit, and offboarding.

Migration uses a strangler strategy: define contracts, create parity tests, replace one bounded boundary, verify exact-SHA behavior, deploy behind isolation or a disabled flag, prove rollback, and remove the old path only after parity.

Teach also serves as a learning source. Generalizable failures become TOS controls, negative fixtures, module updates, and downstream upgrades.
