# TOS Roadmap

## 0.1 Kernel consolidation

Deliver the `tos` CLI, `.tos` canonical state, schemas, contract registry, module manifests, validation wrappers, and status output.

## 0.2 Truth and boot

Deliver repository inspectors, interactive intake, fact classification, conflict and staleness detection, module selection, and project generation.

## 0.3 Scheduler and agent control

Deliver task graph, dependency resolution, work-order compiler, task leases, file and tool scope, handoff, and independent review routing.

## 0.4 Evidence and assurance

Deliver exact-version evidence capture, semantic validation, negative controls, evidence classes, claims reconciliation, and reproducible verification.

## 0.5 Promotion and recovery

Deliver lifecycle promotion, denial explanations, rollback, backup/restore, incident, and recovery management.

## 1.0 Operating system

Deliver safe module lifecycle, provider adapters, downstream upgrades, lesson propagation, Teach reference workload, self-tests, and stable extension contracts.
