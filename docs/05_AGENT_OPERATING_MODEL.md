# Agent Operating Model

Operating functions are distinct even when all are performed by Patrick and AI agents. The owner retains final business, financial, external-authorization, risk-acceptance, promotion, and merge authority unless formally delegated.

The workflow coordinator schedules work. Implementers execute bounded work orders. Independent reviewers compare work to contracts. Evidence verifiers reproduce and classify proof. An implementing agent may not approve its own work.

Every agent action is governed by role, authority, tool permission, work context, work order, task lease, handoff, evaluation, failure/retry, audit, and human-override contracts.
