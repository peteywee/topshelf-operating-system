# Approved Contract Change Records

This directory is the canonical location for **real, owner-approved** TOS contract-change records used by the direct-edit guard.

No YAML record belongs here until all of the following are true:

1. The proposal is structurally valid.
2. The Contract Steward author is recorded.
3. An independent Contract Auditor has passed the change.
4. The Evidence Steward has verified the required evidence packet.
5. Patrick Craven has approved the real TOS change.
6. The Release and Promotion Steward has confirmed target-path and promotion-gate alignment.

Simulation fixtures belong under `examples/contract-changes/`, never in this directory.
